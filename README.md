# Снимок и Пульс — программы для Mac

Нужен Mac на процессоре Apple (M1 и новее).

## Снимок

Скриншоты с пометками, текст с экрана и запись видео. macOS 15 и новее.

- **⌘⇧A** — снимок: тяните рамку или щёлкните по окну; стрелки, рамки, маркер, мозаика, текст, номера; OK, Enter или ⌘C — в буфер.
- **⌘⇧T** — текст с экрана: выделили → ⌘C, и текст уже в буфере. Работает без интернета, русский и английский.
- **⌥⇧R** — запись видео области, ещё раз ⌥⇧R — стоп.

Установка — откройте Терминал (⌘Пробел → «Терминал»), вставьте строку и нажмите Enter:

```
curl -fsSL https://raw.githubusercontent.com/Bajenov/mac-apps/main/install.sh | sh -s snimok
```

Один раз нужно разрешить снимок экрана: Системные настройки → Конфиденциальность и безопасность → «Запись экрана и системного звука» → включите «Снимок» и перезапустите его.

## Пульс

Нагрузка на Mac: ядра и их частота, сколько ватт ест Mac и что именно, запас батареи при текущей нагрузке, кто нагружает Mac, состояние батареи, очистка кэша в Корзину. macOS 14 и новее.

```
curl -fsSL https://raw.githubusercontent.com/Bajenov/mac-apps/main/install.sh | sh -s pulse
```

Обе программы живут значком в строке меню справа сверху, в Доке их нет. Обновить — та же строка ещё раз.
